# Anchors an ensemble driver can run

Anchors an ensemble driver can run

## Usage

``` r
.EnsembleAnchors(anchors, choices)
```

## Arguments

- anchors:

  Character vector of anchor names and start indices.

- choices:

  The named anchors the driver supports.

## Value

`.EnsembleAnchors()` returns the distinct runnable anchors, in order.
