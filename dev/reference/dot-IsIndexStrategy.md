# Is a strategy element a start index?

Is a strategy element a start index?

## Usage

``` r
.IsIndexStrategy(x)
```

## Arguments

- x:

  Character vector, as returned by
  [`.NormaliseStrategy()`](https://ms609.github.io/Coreset/dev/reference/dot-NormaliseStrategy.md).

## Value

`.IsIndexStrategy()` returns a logical vector.
