# Seed for a start-index anchor

Seed for a start-index anchor

## Usage

``` r
.IndexSeed(name, nPts)
```

## Arguments

- name:

  A start index as a string (see
  [`.NormaliseStrategy()`](https://ms609.github.io/Coreset/dev/reference/dot-NormaliseStrategy.md)).

- nPts:

  Integer number of elements.

## Value

`.IndexSeed()` returns the index as an integer, or stops if it exceeds
`nPts`.
