# One randomised greedy construction.

One randomised greedy construction.

## Usage

``` r
.GraspConstruct(d, k, alpha)
```

## Arguments

- d:

  Square distance matrix.

- k:

  Target subset size.

- alpha:

  RCL threshold parameter (alpha=1 -\> greedy, alpha=0 -\> random).

## Value

Integer vector of length k.
