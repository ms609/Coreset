# Peripheral seed index for Gonzalez selection (distance matrix)

Peripheral seed index for Gonzalez selection (distance matrix)

## Usage

``` r
.MaxMinSeed(d, strategy)
```

## Arguments

- d:

  Square numeric distance matrix.

- strategy:

  Anchor name; see
  [`MaxMinSeed()`](https://ms609.github.io/MaxMin/reference/MaxMinSeed.md).
  Also accepts `"first"` (1).

## Value

`.MaxMinSeed()` returns an integer seed index.
